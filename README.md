# 🌐 Push Notifications POC - Web App

Aplicación web para prueba de concepto de notificaciones push con Firebase.

## 🚀 Despliegue en Railway

### Pasos:

1. **Fork o clona este repositorio**
2. **Crea una cuenta en [Railway](https://railway.app/)**
3. **Conecta tu repositorio de GitHub**
4. **Railway detectará automáticamente el proyecto**
5. **Configura las variables de entorno necesarias**
6. **¡Deploy automático!**

### Variables de Entorno:

| Variable | Descripción | Ejemplo |
|----------|-------------|---------|
| `PORT` | Puerto del servidor | `3000` |
| `BACKEND_URL` | URL del backend de notificaciones | `https://tu-backend.railway.app` |
| `NODE_ENV` | Entorno | `production` |

## 🛠️ Desarrollo Local

```bash
# Instalar dependencias

# Ejecutar en modo desarrollo
npm run dev

# Ejecutar en producción
